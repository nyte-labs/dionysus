# Dionysus

A home cocktail bar app for browsing recipes, tracking your inventory, and
finding out what you can make with what's on hand.

## Stack

- Kotlin 2.3
- Spring Boot 4
- H2

## Running locally

Requires JDK 25.

```bash
./gradlew build
./gradlew bootRun
```
